# Phase 0: Circuit Audit and Correctness

## Findings and changes

- Unified flat-statevector ordering to little-endian qubit numbering: qubit `q` is bit `1 << q` for rotations, CNOT permutations, and Pauli readouts. This makes the implemented linear chain match `q0 -> q1 -> q2 -> q3` in the diagram.
- Corrected the Pauli-X expectation formula. Summing `state[i] * state[i xor bit]` across all basis indices already visits both members of each pair, so the previous additional factor of two was incorrect.
- Exposed the statevector and feature readout as separate methods to support direct invariant tests.
- Added result metadata for UTC timestamp, source commit, machine/platform, Python and package versions, and effective CLI arguments.
- Moved the previously committed results and figures to `outputs/legacy/initial_circuit/`. They were generated by the pre-audit implementation and are superseded.

## Verification

- `pytest`: 6 passed.
- Hand-computed RY and CNOT cases pass under the documented little-endian convention.
- State norm error and observable range are checked on batches of random observations.
- All trainable parameters receive finite, nonzero gradients on a fixed generic test input.
- PennyLane `default.qubit` cross-check: 100 random observations and parameter arrays; maximum absolute difference across all eight X/Z features was `3.990876372705898e-07` (limit: `1e-6`).
- Seeded two-episode training smoke test writes per-run JSON with metadata.

## Failures encountered

- The first test run exposed a dtype mismatch in the test fixture; fixed without changing model behavior.
- A later refactor initially left a stale local variable name in the feature method; the full suite caught it, it was fixed, and the final suite passed.

## Gate

The independent simulator discrepancy is below `1e-6`; Phase 0 is complete.
